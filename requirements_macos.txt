# Metal GPU packages (Apple Silicon — install with: pip install --no-build-isolation <url>)
#
# Pinned to exact commits rather than main.tar.gz. These four are developed in
# lockstep with this repo and a floating `main` means two installs a day apart
# can differ silently — which is how the depth-test and BVH-stack bugs below
# went unnoticed. To refresh: bump the SHA and re-run the test suites.
#
# Verified together on M3 Max / macOS 27.2 / torch 2.11.0 / Python 3.13:
#   mtlbvh       011896c  Autorelease pool on the CPU dispatch path (+ Metal 3.1 target, BVH stack 24->64)
#   mtlgemm      c2e5d3f  Metal 3.1 / macOS 14 target, int64 store offsets, sentinel dtype
#   mtlmesh      1493108  Fix per-call GPU memory leak with autorelease pools (+ Metal 3.1 target)
#   mtldiffrast  db3186b  Autorelease pools on the CPU and render paths (+ Metal 3.1 target, keep-first ties)
